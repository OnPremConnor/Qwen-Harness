    Keep the boundaries straight

    Before a question: Uvicorn imports main.py. FastAPI registers the routes. A GET / loads index.html. Those setup actions do not rerun for every chat message.

    For each question: the browser sends POST /chat. The Python route calls the local model server through another HTTP request. Only the current question goes to Qwen.
